# GramSetu – Smart Rural Service Kiosk

![GramSetu Banner](./public/banner.png)

## 🌉 About GramSetu

**GramSetu** is a multilingual touchscreen kiosk platform designed to bridge the gap between rural citizens and essential services.

The platform provides easy access to:

* Government Schemes
* Education & Scholarships
* Agriculture Support
* Healthcare Services
* Employment Opportunities
* Emergency Assistance
* Citizen Services

Through an intuitive touchscreen-first experience, GramSetu empowers citizens to access important information in their preferred language.

---

## 🎯 Problem Statement

Millions of rural citizens face challenges such as:

* Lack of awareness about government schemes
* Long travel distances for information
* Language barriers
* Limited digital literacy
* Difficulty accessing jobs, healthcare, and educational resources

GramSetu addresses these challenges by providing a centralized multilingual digital service kiosk.

---

## 💡 Solution

GramSetu acts as a digital bridge between citizens and opportunities.

Users can access services through a simple touchscreen interface available in:

* English
* हिंदी (Hindi)
* मराठी (Marathi)

The platform is designed to be:

* Accessible
* Inclusive
* Easy to Use
* Touchscreen Optimized
* Senior Citizen Friendly

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/gramsetu-smart-kiosk.git
```

Navigate to the project:

```bash
cd gramsetu-smart-kiosk
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
